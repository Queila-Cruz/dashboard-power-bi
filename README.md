# 🎯 Dashboard de Vendas  | Power BI

Dashboard desenvolvido em **Microsoft Power BI** para análise de desempenho de vendas de produtos, permitindo explorar informações por **localização, categoria, produto e período**.

O projeto faz parte do meu portfólio de **Análise de Dados** e demonstra a aplicação prática de recursos de visualização e exploração de dados para transformar informações comerciais em uma apresentação mais clara e interativa.

---

## 📊 Visão geral

O dashboard foi desenvolvido com uma abordagem voltada para análise de vendas, reunindo indicadores e visualizações que permitem observar diferentes dimensões do negócio.

A página principal do projeto é denominada **“Métricas vendas”** e apresenta uma visão consolidada dos dados.

Entre os principais elementos disponíveis estão:

* Indicadores de **unidades vendidas**
* Indicador de **vendas (£)**
* Análise de vendas por **localização**
* Distribuição por **categoria**
* Análise por **produto**
* Filtro por **mês**
* Visualizações para comparação e identificação de padrões

---

## 🎯 Objetivo do projeto

O objetivo é construir uma visão visual e interativa dos dados de vendas, facilitando a exploração das informações e a identificação de diferentes comportamentos conforme:

**Onde** → localização das vendas
**O quê** → produtos e categorias
**Quando** → período das transações
**Quanto** → unidades vendidas e vendas em £

Essa estrutura permite analisar os dados sob diferentes perspectivas dentro de um único dashboard.

## 📌 Indicadores analisados

Entre os principais indicadores utilizados no dashboard estão:

### Units Sold

Representa a quantidade de unidades de produtos vendidas, permitindo acompanhar o volume comercializado.

### Sales (£)

Representa o valor das vendas em libras esterlinas (£), permitindo observar o desempenho financeiro das vendas.

---

## 🔎 Análises disponíveis

### 🌍 Vendas por localização

O gráfico de colunas permite comparar a quantidade de **unidades vendidas entre diferentes localizações**, facilitando a identificação dos locais com maior volume de vendas.

### 🏷️ Vendas por categoria

A visualização em funil apresenta a distribuição das informações por **categoria de produto**, permitindo observar a participação das diferentes categorias no conjunto analisado.

### 🧸 Produtos

O treemap apresenta os **produtos** de acordo com suas respectivas unidades vendidas, permitindo visualizar de forma rápida quais produtos possuem maior representatividade no volume comercializado.

### 📅 Análise temporal

O dashboard possui um filtro por **mês**, permitindo alterar a análise conforme o período selecionado e explorar diferentes recortes dos dados.
